# 🐱 Spirit Cat

Jogo desenvolvido como projeto prático da disciplina de **Matemática Computacional**.

## 🎮 Sobre o projeto

O jogo consiste em um gato que deve sobreviver ao ataque de diversos espíritos.

Os espíritos surgem pelas extremidades da tela e avançam lentamente em direção ao gato. Para eliminá-los, o jogador deve resolver pequenas equações matemáticas.

O objetivo é sobreviver pelo maior tempo possível e alcançar a maior pontuação.

## 📁 Organização do repositório

O projeto está dividido em duas partes principais:

### `jogo/`

Contém os arquivos relacionados ao desenvolvimento e funcionamento do jogo, incluindo código-fonte, recursos gráficos, sons e demais arquivos necessários para sua execução.

### `documentos/`

Contém os documentos produzidos durante o desenvolvimento do projeto, como levantamento de requisitos, casos de uso, diagramas, protótipos e demais entregáveis da disciplina.

## 🧮 Matemática Computacional

Os conceitos estudados na disciplina serão aplicados às mecânicas do jogo, incluindo a utilização de cálculos matemáticos e algoritmos para a criação dos desafios e funcionamento da partida.
